# StockMatch_Miya-v1.0.0

**StockMatch_Miya-v1.0.0** は、指定した **「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイル** と **「注文品管理表（1ファイル）」** を自動照合し、判定基準日（今日など）時点で **「現品確認日（実際の物を確認した日：A列）」** および **「請求日（伝票を確認した日：AI列）」** がそれぞれ納期を超過している明細を可視化・抽出するデスクトップ業務アプリケーションです。

## 📌 主な機能と特徴

### 1. 注文書と見積依頼書の完全分別（2行目チェック）
* **見積依頼書の自動除外**:
  * 注文書フォルダ内のExcelシートの **2行目** を走査し、「見積」や「見積依頼」などの記載があるシートは自動的にスキップされます。
  * **2行目に「注文」「発注」等の記載がある注文書シートのみを照合対象として抽出** するため、同じフォルダ内やブック内に見積依頼書が混在していても誤って取り込まれることがありません。

### 2. 単価・金額の照合除外（高精度照合）
* **単価・金額を照合対象から完全に除外**:
  * 見積段階の違いや管理表での単価未入力・金額0円による誤った不一致（未記載判定）を防止しました。
  * 照合は **「管理No」「図面番号」「品番」「品名」「仕様」「メーカー」「数量」** のみで行われます。
  * 詳細比較ダイアログでも単価・金額は「— (照合対象外)」として参考表示されます。

### 3. 全体最適照合アルゴリズム（誤マッチ・重複誤判定の完全防止）
* **全体最適マッチング**:
  * 手前の明細から早い者勝ちで管理表行を消費する方式を排除。
  * 同一管理No内の全注文書明細と管理表の候補行の間で、全体として最も整合性が高くなる最適な1対1ペアを自動決定します。
  * 別会社（例：不二精研）の注文書がキーエンス等の管理表行を誤って先取り消費してしまう問題を防止しています。

### 4. 「どこが不一致か」が一目でわかる不一致診断・項目別比較機能
* 一覧テーブルの2列目に **「不一致理由・照合診断」** 列を搭載：
  * **【管理No未登録 / 管理No不一致】**: 注文書ファイル名先頭8桁の管理Noが管理表に1件も存在しない場合。
  * **【項目不一致】**: 管理Noは管理表に存在するものの明細が一致しなかった場合、同一管理No内で最も近い候補行を特定し、「図番」「品番」「品名」「仕様」「数量」のどれが一致し、どれが不一致なのかを表示。
* **ダブルクリックで詳細比較ウィンドウを起動**:
  * 一覧の行を **ダブルクリック**（または「🔍 選択行の不一致・照合詳細を表示」ボタンをクリック）すると、注文書と管理表の記載内容を並べて比較できます。

### 5. 管理No（ファイル名先頭8桁）の完全一致照合ルール
* **注文書ファイル名の頭から8桁を「管理No（注文番号）」として厳密に取得** します（例: `22609051購依不二精研（株）注文.xlsx` ⇒ 管理No: `22609051`）。
* 管理表の中にこの管理No（8桁）が存在しない場合は、無条件で「【不一致】管理表未記載」と判定されます。

### 6. 注文書フォルダ（サブフォルダ含む全階層）の一括検査
* 注文書が入った親フォルダを指定すると、**配下の全サブフォルダ内も再帰的に自動探索** して注文書Excelをまとめてスキャン・検査します。
* 一時ファイル（`~$`）や管理表自身、無関係なExcelは自動的にスキップされます。

### 7. 起動時フルスクリーン最大化表示 & 設定保存先の厳重ブロック (`C:\StockMatch\config.json` 専用固定)
* アプリ起動時にデスクトップ画面いっぱいに **自動最大化** して起動します。
* パス設定の保存先は `C:\StockMatch\config.json` に厳格固定されており、他ディレクトリへの書き込みはプログラム側で完全にブロックされます。

## 💻 動作環境・必要ライブラリ
* **OS**: Windows 10 / 11
* **Python**: 3.9 以上
* **必要ライブラリ**:
  * `openpyxl >= 3.1.2`
  * `pandas >= 2.1.0`
  * `scipy >= 1.9.0` (線形和割り当て最適化用。未インストールの環境でも自動フォールバックで動作します)
  * `tkinter`（Python標準付属）

## 📖 使い方
1. **アプリを起動**:
   ```bash
   python app.py
   ```
2. **パスの設定と照合実行**:
   * **① 注文品管理表ファイル** と **② 注文書フォルダパス** を選択し、**「照合・遅延チェック実行」** ボタンを押します（F5キーでも可）。
3. **結果の確認**:
   * テーブルで現品・請求の超過や不一致を確認します（見積依頼書は自動除外され、注文書のみが並びます）。
   * 行を **ダブルクリック** することで、項目別詳細比較を確認できます。
