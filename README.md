# StockMatch_Miya-v1.5.0

StockMatch_Miya-v1.5.0 は、指定した「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイルと「注文品管理表（1ファイル）」を双方向で自動照合し、判定基準日（今日など）時点で「現品確認日（実際の物を確認した日：A列）」および「請求日（伝票を確認した日：AI列）」がそれぞれ納期を超過している明細、ならびに「注文書未検出（管理表にあるのに注文書が見当たらない未発注明細）」を個別のタブで明確に分離して可視化・抽出するデスクトップ業務アプリケーションです。

---

## 主な機能と特徴

### 1. 注文品管理表に準拠した見やすい表示列と「表示列設定」機能（全18列・設定保存対応）
* 注文品管理表と同じ列順で見やすく整理:
  * 画面の一覧（照合結果一覧および注文書未検出一覧）は、注文品管理表（K列〜AH列）の並び順に準拠した分かりやすい列構成に統一されています。
  * 表示列一覧（全18項目）:
    1. 総合判定（または状態判定）
    2. 不一致理由・照合診断（または未検出診断内容）
    3. 納期（※管理表に納期が記載されていれば優先して管理表納期、それ以外は注文書納期を参照）
    4. プロジェクト名
    5. 管理No
    6. 出荷先
    7. 品名、ライン名等
    8. 製品詳細
    9. 製作数
    10. 図面番号
    11. 品番
    12. 品名
    13. メーカー
    14. 単数
    15. 仕様
    16. 仕入先
    17. 在庫数
    18. 注文日（※注文書の日付を参照）
* 表示列の自由なカスタマイズ:
  * 照合結果一覧（タブ①）の上部ツールバーにある「👁 表示列の設定...」ボタン、またはメニューバーの「設定(S)」→「照合結果一覧の表示列設定...」をクリックすると、専用の設定画面が開きます。
  * チェックボックスをON／OFFするだけで、画面上の表示列をいつでも直感的にカスタマイズできます。
* 設定ファイル（config.json）への保存に対応:
  * 設定画面内の「💾 適用して保存」ボタンを押すことで、選択した表示列設定が `config.json` に保存され、次回アプリ起動時にも自動的に復元・適用されます。

### 2. 注文品管理表の納期（AH列）優先参照 ＆ 日付型判定機能
* 管理表AH列納期の最優先適用:
  * 注文品管理表のAH列（34列目：納期列）に納期が記入されている場合、注文書側に書かれている納期ではなく、注文品管理表の納期を最優先で参照して納期超過・遅延チェックを行います。
* 日付型判定による誤判定の防止:
  * 注文品管理表のAH列のセル値が「日付型（Excelの表示形式が日付で日付として入力されているセル）」である場合のみ納期として有効判定します。
  * 管理表のAH列に「未定」「要確認」「相談」「都度」「4月中旬」などの文字列メモや日付型以外の値が入っている場合は、誤判定を防ぐため自動的に無視され、従来通り注文書に記載されている本来の納期（または注文日＋指定猶予日数）を参照します。

### 3. 注文品管理表の「指示書列(J列)」フィルター機能（デフォルト: 「有り」のみ・設定保存対応）
* 指示書列(J列)によるワンクリック絞り込み:
  * 注文品管理表の10列目（J列：指示書列）を自動で読み取り、一覧表に「指示書(J列)」列として表示するとともに、画面上部の「④ 一覧から除外する管理No」行の右側に搭載された「📋 管理表 指示書列(J列)フィルタ」コンボボックスから表示対象をワンクリックで切り替えられます。
  * 以下の4つのフィルターモードから選択できます（初期値: `「有り」のみ`）:
    1. `「有り」のみ`（初期値）: J列に「有り（有・〇等）」と記載されている明細のみを表示します。
    2. `有り または 空白 のみ`: J列が「有り」または「空白（未入力）」の明細のみを表示し、「無し（無・不要・×・ー等）」と記載されている対象外明細を自動的に除外します。
    3. `「空白」のみ`: J列が空白（未入力）の明細のみを表示します。
    4. `すべて表示 (フィルタなし)`: J列の値にかかわらずすべての明細を表示します。
  * コンボボックスを切り替えると、再スキャンを行わなくても表示中の照合結果一覧・注文書未検出一覧・件数サマリーカード・Excel出力へ即座に反映されます。
  * 「💾 設定を保存」ボタンを押すことで、選択した指示書列フィルタ条件も `config.json` に保存され、次回起動時に自動復元されます。
* 注文品管理表の「出荷先」「品名・ライン名等」「製品詳細」も一覧表示:
  * 照合結果一覧・注文書未検出一覧・管理表プレビュー・Excel出力のすべてに、注文品管理表の「出荷先（N列）」「品名・ライン名等（O列）」「製品詳細（P列）」を表示し、キーワード検索や列ごとのExcel風チェックボックス絞り込みにも対応しています。

### 4. 注文日からの経過月数による自動除外機能（デフォルト: 12ヶ月・設定保存対応）
* 古い注文データの自動除外:
  * 画面上部の「③ 判定基準日 (今日)」行にある「経過除外: 注文日から [ 12 ] ヶ月経過で除外」欄にて、注文日から何ヶ月経過したデータを除外するか自由に設定できます（初期値: 12ヶ月）。
  * 判定基準日時点で、注文日（注文書4行目の注文日など）から指定したヶ月数以上が経過している明細は、照合結果一覧・注文書未検出一覧・件数サマリー・Excel出力から自動的に除外されます。
  * 数値を変更して Enter キーを押す（または入力欄から移動する）と、再スキャンを行わなくても表示中の一覧や件数サマリーへ即座に反映されます（※「0」を入力すると経過月数による除外を行わず全期間のデータを表示します）。
* 設定ファイル（config.json）への保存に対応:
  * 「💾 設定を保存」ボタンを押すことで、設定した経過除外月数が `config.json` に保存され、次回アプリ起動時にも自動的に復元・適用されます。

### 5. 設定ファイル (config.json) の保存先指定 ＆ ボタン一つで初期値復帰
* 設定ファイルの保存場所を自由に指定可能:
  * 画面上部の「③ 判定基準日 (今日)」行にある「⚙ 保存先設定...」ボタン、またはメニューバーの「設定(S)」→「設定ファイル(config.json)の保存先を指定・変更...」から、設定ファイル（config.json）の保存先フォルダを自由に変更できます。
  * 社内共有サーバー（NAS）やGoogleドライブ等のクラウド同期フォルダを指定することで、複数端末で同一の除外設定やパス設定を共有することも可能です。
* ボタン一つでアプリと同じ場所（初期値）に戻す機能:
  * 保存先設定画面内の「🏠 アプリと同じ場所 (初期値) に戻す」ボタンをクリックするだけで、いつでもワンクリックで初期値（アプリ配置フォルダ）へ戻すことができます。
  * メニューバーの「設定(S)」→「設定ファイルの保存先をアプリ配置フォルダ(初期値)に戻す」からも直接復帰できます。
* 既存設定の自動引き継ぎ機能:
  * 保存先を変更する際、「変更前の設定内容を新しい保存先へ自動コピーして引き継ぐ」オプションが初期状態で有効になっているため、保存先を変更しても入力済みのパスや除外設定が消えることなくスムーズに移行できます。

### 6. 専用ウィンドウでの除外管理No設定 ＆ Excel複数セル直接貼り付け対応
* 分かりやすい行区切り入力と専用ウィンドウ:
  * 画面上部の「④ 一覧から除外する管理No」にある「🚫 除外する管理Noを設定・編集...」ボタンをクリックすると、専用の設定画面が別ウィンドウで開きます。
  * 1行に1件ずつ管理Noが縦に並ぶ見やすいエディタ形式となっており、除外したい管理Noを簡単・確実に入力・確認・編集できます。
* Excelからコピーした複数セルの直接貼り付け（Ctrl+V）に対応:
  * Excelの注文品管理表や管理Noリストから対象のセル（縦一列や複数行・複数列の範囲）をまとめてコピー（Ctrl+C）し、設定画面でそのまま「貼り付け（Ctrl+V）」または「📋 クリップボードから貼り付け」ボタンを押すだけで、何十件〜何百件もの管理Noを一括で登録できます。
  * コピー時に不要な空白・タブ・カンマが含まれていても、自動的に1行ずつの管理Noに分解し、重複や空行を自動整理（「✨ 重複・空白を整理」）します。
* ワンクリックで一覧・サマリーへ即時反映 ＆ 自動保存:
  * ウィンドウ右下の「✔ 適用して設定を保存」ボタンを押すだけで、すでに表示中の照合結果一覧および件数サマリーから該当の管理Noが即座に除外され、設定ファイル（config.json）にも自動保存されます（再スキャン不要）。
  * メイン画面には「✔ 除外指定中: 5件 (22609030, 22609051...)」のように設定状況がバッジ表示され、「全解除」ボタンでいつでもワンクリックで一括クリアできます。
* フォルダ探索の更なる高速化（枝刈りスキップ連携）:
  * 除外設定された管理Noは注文書フォルダの探索対象からも除外されるため、配下のサブフォルダ探索時に「不要なフォルダ」として丸ごとスキップされ、無駄なファイル読み込みが発生せず照合処理がさらに高速化します。

### 7. 大量フォルダ・Googleドライブ・社内ネットワーク環境でも快適な「超高速照合エンジン」
* 管理Noフォルダ単位の丸ごとスキップ（枝刈りスキャン）:
  * 注文書フォルダの中に1,000個以上のサブフォルダが存在する場合でも、サブフォルダ名に記載された8桁の「管理No」を自動判定します。
  * 注文品管理表に載っていない管理No（および除外設定された管理No）のサブフォルダは、フォルダの中身を一切開かずにフォルダごと丸ごとスキップするため、Googleドライブ等のクラウド同期フォルダや社内ネットワーク共有フォルダ（`\\サーバー名\共有名` 等）上でも無駄な通信や待ち時間が発生しません。
* ファイル名事前フィルタリングと見積依頼書の早期除外:
  * Excelファイルを開く前にファイル名から管理Noや書類種別を高速判定し、管理表にない注文書や見積専用ファイルを瞬時に除外します。
  * シート読み込み時も、2行目に「見積」の記載があるシートはその場で即座に読み取りを打ち切り、「注文書」シートのみを高速に抽出します。
* マルチスレッド並列読み込み ＆ メモリキャッシュ機構:
  * 絞り込まれた対象の注文書Excelファイルを複数同時に並列で読み込むことで、ファイル読込時間を大幅に短縮しています。
  * 一度読み込んだ注文書および管理表のデータは、ファイルの更新日時・サイズとともにメモリに記憶（キャッシュ）されるため、アプリを起動したまま基準日を変えて再照合したり、管理表を更新して再チェックしたりする際は数秒で瞬時に完了します。

### 8. 直感的なコントロールパネル配置 ＆ 実行中の中止機能
* 入力と実行がひと目で分かるレイアウト:
  * 上部パネルは「①管理表ファイル選択」「②注文書フォルダ選択」「③判定基準日・超過日数・経過月数除外設定・設定保存」「④除外する管理No・指示書列(J列)フィルタ」の入力エリアと、「⑤進捗状況 ＆ 照合実行」の実行エリアに綺麗に分離・整理されています。
  * 「💾 設定を保存」ボタンと「⚙ 保存先設定...」ボタンは「③ 判定基準日 (今日)」行の右側に並んで配置され、設定入力後にワンクリックで設定ファイルへ保存したり保存先を変更したりできます。
  * メイン操作である「▶ 照合・遅延チェック実行 (F5)」ボタンは、進捗状況行の右端に大きく力強いロイヤルブルーの目立つボタンとして配置され、迷わず直感的に操作できます。
  * 「📊 Excelで直接開く」ボタンは、照合結果を確認する「現在の表示フィルタ」行（一覧の上部右端）に配置され、絞り込み状況を確認しながらスムーズにExcel展開へ進むことができます。
* 照合実行中の安心な「中止」機能（ボタン ＆ Escキー対応）:
  * 照合・遅延チェックの実行中は、実行ボタンの左隣にある「⏹ 中止 (Esc)」ボタンが赤く有効化されます。
  * 誤ったフォルダを指定してしまった場合や処理を途中で止めたい場合、「⏹ 中止 (Esc)」ボタンを押すか、キーボードの「Esc」キーを押すだけで、いつでも安全かつ即座に照合処理を中断できます。

### 9. 件数サマリー一体型のワンクリック表示フィルタ ＆ 2系統タブ分離表示
* 8枚の件数表示カードと表示フィルタの一体化:
  * 画面中段の8つの件数サマリーカードそれぞれにフィルター切替ボタンを搭載しており、カードまたはボタンをクリックするだけで該当する明細一覧へ即座に絞り込まれます。
  * 現在選択中のカードは太枠カラーラインと「✔ フィルター表示中」ボタンで強調表示され、一覧上部の「現在の表示フィルタ」バッジにもリアルタイムで表示件数が反映されます。
    1. 注文書明細 総数: 注文書から検出された全明細を表示します。
    2. すべての異常(超過・不一致): 納期超過・伝票未着・不一致・管理表未記載など、確認が必要な異常案件をすべてまとめて表示します。
    3. 【警告】現品・請求の両方超過: 納期を過ぎても「現品確認日(A列)」と「請求日(AI列)」の両方が未記入の最重要確認案件を表示します（※照合実行時の初期表示フィルタ）。
    4. 【現品超過】現品確認日の超過: 請求日は記入済みですが、現品確認日(A列)が未記入のまま納期を過ぎている案件を表示します。
    5. 【請求超過・未着】請求日(伝票)超過: 現品は確認済みですが、請求日(AI列)が未記入のまま納期を過ぎている案件、または現品確認日から長期間伝票が届いていない案件を表示します。
    6. 【不一致】管理表との不一致: 注文書と管理表で品名・品番・図番・数量などが食い違っている案件、および注文書はあるが管理表に記載がない案件を表示します。
    7. 正常・納期前・確認済: 現品・請求ともに確認済みの案件、またはまだ納期前の正常な案件を表示します。
    8. 【別タブ】注文書未検出: 管理表に記載があるのに注文書Excelが見つからない案件数を表示します。クリックすると自動的にタブ②へ切り替わります。
* タブ①『納期超過・照合結果 一覧』:
  * 注文書が存在する案件の納期超過（現品確認・請求日）および、管理表との項目照合結果・管理表未登録案件を一覧表示します。注文品管理表のAH列に納期がある場合は管理表納期が優先され、日付型以外のメモ等は無視されて注文書納期が参照されます。
* タブ②『【未発注・注文書なし】管理表のみ記載 一覧』:
  * 注文品管理表に明細が登録されているにもかかわらず、注文書フォルダ内に注文書Excelが存在しない未手配・未発注案件だけを独立して一覧表示します。
  * 【AB列「購入数」0の自動除外】注文品管理表のAB列（28列目）「購入数」を正確に参照し、購入数が「0」（または「0個」「0台」等）となっている在庫充当品や発注不要項目は未発注一覧から自動的に除外されます。

### 10. 納期表記の柔軟な自動変換（上旬・中旬・下旬・月末等）および納期未記載時の自動期日算出
* 期間表記の自動期日変換:
  * 「11/上」「11/上旬」「11月上旬」「11月上」「11/初」「11月初旬」「11月頭」などが含まれる場合、その月の10日（例: 11月10日）までとして判定します。
  * 「11/中」「11/中旬」「11月中旬」「11月中」「11/中頃」「11月半ば」などが含まれる場合、その月の20日（例: 11月20日）までとして判定します。
  * 「11/下」「11/下旬」「11月下旬」「11月下」「11/末」「11月末」「11月末日」「11月いっぱい」「11月内」などが含まれる場合、その月の最終日（例: 11月30日、12月31日、2月28日/29日）までとして判定します。
  * 「11/前半」（15日まで）、「11/後半」（月末まで）、「11/上～中」「11/10～15」などの期間幅表記（後ろの期日を基準に判定）、および和暦（令和・R表記）や年省略表記にも対応しています。
* 納期未記載（空白）時の注文日基準判定:
  * 注文書明細の納期が空欄（未記載）の場合、注文書4行目に記載されている「注文日（発注日付）」を自動抽出します。
  * 注文日から指定日数（初期値: 7日）を加算した日を期限として超過判定を行います。一覧の「注文書納期」列には「未記載 (2026-11-02注文+7日)」のように算出根拠が明記されます。

### 11. 注文品管理表・注文書のピンポイント直接参照＆注文書の厳重な誤保存・誤編集ブロック機構
* 該当シート・該当行へのExcelダイレクトジャンプ:
  * 一覧で明細を選択し、ツールバーの「📄 注文書を参照 (読取専用)」「📋 管理表を参照」ボタンを押すか、行を「右クリック」してメニューを選択すると、実際の注文書Excelまたは注文品管理表Excelを開き、該当するシートの該当行を自動選択（スクロール移動・ハイライト）した状態で表示します。
* 注文書の多重誤保存・誤編集ブロック（5重の安全保護）:
  * 注文書をアプリからExcelで開く際は、予期せず間違って編集・上書き保存してしまう事故を完全に防ぐため、以下の5重の保護が自動的に適用されます。
    1. 強制読み取り専用オープン: 常にExcelの「読み取り専用（ReadOnly）」モードで開きます。
    2. 既存ブックの読み取り専用強制切り替え: すでにExcel上でその注文書が通常モードで開かれていた場合でも、自動的に読み取り専用モードへ切り替えます。
    3. メモリ上の全シート＆ブック構造ロック: 開いた注文書シートに対してメモリ上で編集保護ロック（セル選択・スクロール・コピーは可能、文字入力やセル書き換え・行列削除は禁止）を適用します。
    4. 閉じる際の「変更を保存しますか？」ポップアップ抑止: 注文書内の日付関数（TODAY関数等）の再計算によってExcel終了時に「変更を保存しますか？」と聞かれる現象自体を抑止し、そのまま安全に閉じられるように制御します。
    5. 通常モード起動の完全遮断とファイル書き込み禁止ガード: 万が一Excel連携機能が使用できない環境でも通常モード（編集可能）で開くことを厳重にブロックし、アプリ自身も注文書や管理表ファイルへの書き込みを一切行わない安全設計となっています。
* 詳細ウィンドウ内の3タブ構成（アプリ内シートプレビュー）:
  * 一覧の行をダブルクリック（または「🔍 照合詳細・プレビュー」ボタンをクリック）すると開く詳細ウィンドウに、以下の3つのタブを搭載しています。
    1. 『① 🔍 項目比較・診断レポート』: 注文書と管理表の項目ごとの比較と不一致理由の診断を表示します。
    2. 『② 📄 注文書シート参照 (プレビュー)』: Excelを開かなくても、注文書シートの記載内容（4行目の注文日や明細行など）をアプリ内の表で安全に確認でき、該当明細行が黄色でハイライト表示されます。
    3. 『③ 📋 注文品管理表参照 (同一管理No・周辺行)』: 管理表内の該当シートの内容（指示書(J列)・出荷先・品名/ライン名等・製品詳細を含む）をアプリ内で即座に一覧確認でき、該当行へ自動スクロール＆ハイライト表示されます。

### 12. 一時ファイルなしでExcel新規ブックへ直接展開 ＆ 中止機能・最適な印刷設定
* 「📊 Excelで直接開く」機能（ショートカットキー: Ctrl + S）:
  * ディスク上に一時ファイルを作成せず、Excelの新規ブック（未保存のBook）を直接起動して全データを即座に転送・展開します（「納期超過・照合結果」「注文書未検出(管理表のみ)」の2シート構成）。
  * アプリと同じ配色（薄赤・薄橙・薄黄・薄紫・琥珀色）を再現し、1行目の見出し固定（FreezePanes）とオートフィルターが自動設定されます（除外管理No、注文日経過月数、および指示書列(J列)フィルタの設定が適用された状態で出力されます）。
* Excel展開実行中の中止機能（ボタン ＆ Escキー対応）:
  * 「📊 Excelで直接開く」ボタンを押してデータ転送を実行している最中は、ボタンの左隣に赤色の「⏹ 中止」ボタンが現れ、進捗行の「⏹ 中止 (Esc)」ボタンやキーボードの「Esc」キーでも、作成途中のブックを破棄して安全かつ即座に中断できます。
* 業務帳票としての最適な印刷設定（自動適用）:
  * 用紙は「A4サイズ・横向き」、横幅1ページ収まり（FitToPagesWide=1）、2ページ目以降の見出し行自動繰り返し、ヘッダー（帳票名・作成日）・フッター（ページ番号）、枠線印字が自動設定され、そのまま印刷・PDF化が可能です。

### 13. 高精度マッチング＆単価・金額の除外
* 単価未入力や金額0円、消費税表記の違いによる誤判定を防ぐため、単価・金額は照合計算から完全に除外しています。
* 照合は「①管理No(8桁)」「②図面番号」「③品番」「④品名」「⑤仕様・規格」「⑥発注先・メーカー」「⑦購入数(AB列)」で全体最適1対1マッチングを行います。

### 初回起動時のWindows Defender（SmartScreen）警告への対応手順

初めて本アプリを実行した際、Windowsのセキュリティ機能（Microsoft Defender SmartScreen）により以下の青い警告画面が表示される場合があります。

> 「WindowsによってPCが保護されました」
> 「Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起きる可能性があります。」

この警告が表示された場合は、故障やウイルスではありませんので、以下の手順で実行してください。

1. 警告画面の文章の下にある「詳細情報」という文字（リンク）をクリックします。
2. 画面の右下に「実行」ボタンが新しく表示されます。
3. 「実行」ボタンをクリックすると、アプリが正常に起動します。

※2回目以降の起動時はこの警告画面は表示されなくなります。

## 基本的な使い方（ステップバイステップガイド）

### STEP 1 : 注文品管理表と注文書フォルダの指定
1. アプリを起動します（画面は自動的に最大化されて見やすく開きます）。
2. 「① 注文品管理表ファイル」の右にある「ファイルを参照...」ボタン（または Ctrl+O）を押し、管理表Excel（例: 注文品管理表.xlsx）を選択します。
   * 右端の「📋 管理表を開く」ボタンを押すと、指定した管理表をいつでも直接Excelで開けます。
   * 管理表がExcelで開かれたままでも、アプリが安全に一時コピーを作成して読み取るため、Excelを閉じずにそのまま照合できます。
3. 「② 注文書フォルダパス」の右にある「フォルダを参照...」ボタン（または Ctrl+D）を押し、注文書Excelが保管されている親フォルダ（例: 依頼ファイル）を選択します。
   * 右端の「📂 フォルダを開く」ボタンを押すと、注文書フォルダをエクスプローラーで直接開けます。
   * 親フォルダの中に多数の管理No別サブフォルダがある場合でも、管理表に存在する管理Noのフォルダだけを自動判別して高速に探索します。

### STEP 2 : 判定基準日・納期未記載時の日数・経過月数除外・設定の保存
1. 「③ 判定基準日 (今日)」には、納期超過を判定する基準日（初期値は当日の日付）が YYYY-MM-DD 形式で入っています。別の日付を入力して確認することもでき、「今日に戻す」ボタンでいつでも当日に戻せます。
2. 「納期未記載時: 注文日(4行目)から [ 7 ] 日経過で超過」には、注文書明細の納期欄が空欄の場合に、注文書4行目の「注文日」から何日経過したら超過とみなすか（初期値: 7日）を指定します。
3. 「経過除外: 注文日から [ 12 ] ヶ月経過で除外」には、注文日から何ヶ月経過した古いデータを一覧や集計から除外するか（初期値: 12ヶ月）を指定します（※0を入力すると経過月数による除外を行いません）。
4. 右端の「💾 設定を保存」ボタンを押すと、「①管理表パス」「②注文書フォルダパス」「③納期未記載時の超過日数」「③注文日からの経過除外月数」「④除外する管理Noリスト」「④指示書列(J列)フィルタ設定」「表示列設定」が設定ファイル（config.json）に保存され、次回起動時に自動で復元されます。
5. 設定ファイル（config.json）の保存場所を変更したい場合は、「💾 設定を保存」の左隣にある「⚙ 保存先設定...」ボタンを押します。任意のフォルダを指定できるほか、「🏠 アプリと同じ場所（初期値）に戻す」ボタン一つでいつでも初期状態（アプリと同じフォルダ）に戻せます。

### STEP 3 : 除外する管理Noの設定 ＆ 指示書列(J列)フィルタの選択
1. 照合結果や未発注一覧に表示したくない管理Noがある場合は、「④ 一覧から除外する管理No」の「🚫 除外する管理Noを設定・編集...」ボタンをクリックします。
2. 専用の設定ウィンドウが開きますので、除外したい管理Noを「1行に1つずつ（改行区切り）」で入力します。
   * Excelのセルから複数の管理Noをまとめてコピー（Ctrl+C）し、設定ウィンドウの「📋 クリップボードから貼り付け」ボタンを押す（または Ctrl+V）だけで、自動的に行区切りで一括入力されます。
   * 「✨ 重複・空白を整理」ボタンで、重複や空行を綺麗に整理できます。
3. 「✔ 適用して設定を保存」ボタンを押すと、設定ファイルへ自動保存されると同時に、現在表示中の照合結果一覧・件数サマリーからも即座に除外が反映されます。
4. 同じ④行の右側にある「📋 管理表 指示書列(J列)フィルタ」から、注文品管理表のJ列（指示書列）による絞り込み条件（初期値: `「有り」のみ`）を選択できます。選択を切り替えると即座に一覧・サマリーに反映されます。

### STEP 4 : 照合・遅延チェックの実行と処理の中止
1. 「⑤ 進捗状況」行の右端にある青い「▶ 照合・遅延チェック実行 (F5)」ボタンを押す（またはキーボードの F5 キーを押す）と、照合処理が開始されます。
2. 実行中はプログレスバーと進捗メッセージに現在の処理ステップと進捗件数がリアルタイム表示されます。
3. 実行中に処理を止めたい場合は、実行ボタンの左隣にある赤い「⏹ 中止 (Esc)」ボタンを押すか、キーボードの Esc キーを押すことで、いつでも安全に中断できます。

### STEP 5 : 件数サマリーカードと2つの独立タブによる確認
1. 照合が完了すると、画面中段の8枚のサマリーカードに件数が表示されます。見たいカードまたはカード下部のボタン（「▼ この条件で表示」など）をクリックすると、該当する明細一覧にワンクリックで切り替わります（初期表示は最も優先度の高い「【警告】現品・請求の両方超過」が選択されています）。
2. 下部の一覧エリアは2つの独立したタブに分かれています:
   * 「① 納期超過・照合結果 一覧」タブ: 注文書が存在する案件の納期超過や管理表との不一致を確認します。注文品管理表の列順に準拠した18列で表示され、必要に応じて「👁 表示列の設定...」ボタンから表示列を自由に変更できます。注文日は注文書の日付、納期は管理表AH列に日付型で記載されていれば管理表納期が優先され、それ以外は注文書納期が参照されます。
   * 「② 【未発注・注文書なし】管理表のみ記載 一覧」タブ: 管理表に記載があるのに注文書ファイルが見つからない未発注案件を確認します（右端の「【別タブ】注文書未検出」カードからもワンクリックで移動できます）。同じく注文品管理表準拠の18列で統一表示されます。

### STEP 6 : 表示列設定・検索・詳細プレビュー・元ファイル参照・Excel直接出力
* 表示列の設定: 一覧上部の「👁 表示列の設定...」ボタン（またはメニュー「設定」→「照合結果一覧の表示列設定...」）をクリックすると、一覧に表示したい列を自由に選択・保存できます（初期値は18列表示）。
* キーワード検索: 一覧上部の「キーワード検索」欄に文字を入力すると、プロジェクト名・管理No・出荷先・品名/ライン名等・製品詳細・製作数・図番・品番・品名・メーカー・仕様・仕入先・在庫数・納期・不一致理由などをリアルタイムで絞り込めます。
* 列フィルター・並べ替え: 一覧の各列タイトル（▾）をクリックすると、Excel風のチェックボックス絞り込みや昇順・降順ソートが行えます（「列フィルター解除」ボタンで一括解除）。
* 照合詳細・アプリ内プレビュー: 一覧の行をダブルクリック（または「🔍 照合詳細・プレビュー」ボタンを押す）と、項目別の比較表に加え、アプリ内で注文書シートや管理表シートを直接閲覧できるプレビュー画面が開きます。
* 注文書・管理表をExcelで直接参照: 行を選択して「📄 注文書を参照 (読取専用)」または「📋 管理表を参照」ボタンを押す（または行を右クリックする）と、Excelで該当ファイルの該当シート・該当行がハイライト選択された状態で開きます（注文書は5重の保護ロックにより誤って上書き保存される心配がありません）。
* Excel新規ブックへ直接出力: ツールバー右端の緑色の「📊 Excelで直接開く」ボタン（または Ctrl+S）を押すと、一時ファイルを作らずにExcelの新規ブックを立ち上げ、色分け・フィルター・A4横印刷設定済みの表を直接出力します（出力中も左隣の「⏹ 中止」ボタンや Esc キーで中断可能です）。

## キーボードショートカット・マウス操作一覧

* F1 キー : アプリ内の「ヘルプ＆操作ガイド（取扱説明書）」を開く
* F5 キー : 「▶ 照合・遅延チェック実行」を開始する
* Esc キー : 実行中の処理（照合・遅延チェック または Excel直接展開）を安全に中止する
* Ctrl + O : ① 注文品管理表ファイルを選択する
* Ctrl + D : ② 注文書フォルダを選択する
* Ctrl + S : 照合結果を「📊 Excelで直接開く」（新規ブック展開）
* Alt + F4 : アプリケーションを終了する
* 行をダブルクリック : 照合詳細・アプリ内シートプレビュー画面を開く
* 行を右クリック : コンテキストメニュー（詳細表示／注文書参照／管理表参照／フォルダを開く）を開く
* 列ヘッダーを左クリック : Excel風 列フィルター＆ソートメニューを開く
