# StockMatch_Miya-v1.0.0

**StockMatch_Miya-v1.0.0** は、指定した **「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイル** と **「注文品管理表（1ファイル）」** を双方向で自動照合し、判定基準日（今日など）時点で **「現品確認日（実際の物を確認した日：A列）」** および **「請求日（伝票を確認した日：AI列）」** がそれぞれ納期を超過している明細、ならびに **「注文書に無い項目（管理表のみ）」** や **「管理表に無い項目（注文書のみ）」** を個別のタブで明確に分離して可視化・抽出するデスクトップ業務アプリケーションです。

## 📌 主な機能と特徴

### 1. タブ分離による2系統の独立一覧表示（視認性強化）

目的別に2つのタブに完全に分離し、選択中タブの濃紺強調・動的インジケーター（`【選択中】▶ `）で視認性を高めています：

* **タブ①『納期超過・照合結果 一覧』**:
  * 注文書が存在する案件の納期超過（現品確認・請求日）および、注文書にあるのに管理表に未登録の案件（【不一致】管理表未記載）を一覧表示。

* **タブ②『【未発注・注文書なし】管理表のみ記載 一覧』**:
  * 注文品管理表に明細が登録されているにもかかわらず、注文書フォルダ内に注文書Excelが存在しない未手配・未発注案件だけを独立して一覧表示。
  * **★【AB列「購入数」0の完全除外】**: 注文品管理表の **AB列（28列目）「購入数」** を正確に参照し、購入数が `0`（または `0.0`、全角の `０` 等）となっている在庫充当品や発注不要・キャンセル等の項目は未発注一覧から自動的に除外されます。
  * 管理表のシート名、行番号、管理No、業者/メーカー、品名、型番、数量（購入数）、管理表納期、現品/請求確認状況、担当者をクリアに確認可能。

### 2. 注文品管理表にある管理No（8桁）の項目のみを自動照合

* まず「① 注文品管理表ファイル」を読み込み、管理表内に登録されているすべての **管理No（8桁）** を自動的に収集します。
* 「② 注文書フォルダ」内（サブフォルダ含む全階層）を走査する際、**注文品管理表に存在する管理Noと一致する注文書・明細のみを照合対象** として抽出し、管理表に存在しない管理Noの注文書ファイルは自動的にスキップします。

### 3. 単価・金額の照合除外＆全体最適マッチング

* **単価・金額を照合対象から完全に除外**:
  * 管理表での単価未入力・金額0円、または税抜/税込の表記差による誤った不一致判定を防止。
  * 照合は **「①管理No」「②図面番号」「③品番」「④品名（管理表T列/O列）」「⑤仕様・規格」「⑥発注先・メーカー」「⑦購入数(数量: AB列)」** で行われます。
* **全体最適1対1マッチング**:
  * 同一管理No内の全明細と管理表候補行の間で、全体として最も整合性が高くなる最適な1対1ペアを自動決定。他業者の注文書による誤った先取り消費を完全に防ぎます。

### 4. アプリ全ウィンドウへの `icon.ico` 適用（タスクバー対応）

* アプリと同じフォルダに配置された **`icon.ico`** を自動的に読み込み、メイン画面・不一致詳細比較ウィンドウ・ヘルプ画面・列フィルター画面・各種ダイアログのすべてにアイコンを設定します。
* Windowsのタスクバー上でもPython標準アイコンではなく、`icon.ico` が独立したアプリアイコンとして表示されます。

### 5. 2シート同時Excelエクスポート

* 「CSV/Excel出力」（`Ctrl+S`）実行時、Excel出力（`.xlsx`）を選択すると、
  * シート1: **納期超過・照合結果**
  * シート2: **注文書未検出(管理表のみ)**（※購入数0は除外済）
  の2つのシートに自動的に分けて出力されます。

## 🎨 画面上の行ハイライト・判定色一覧

### タブ①: 納期超過・照合結果 一覧

| 総合判定表示 | 背景色 | 状態・内容 |
| :--- | :--- | :--- |
| **【不一致】管理表未記載** | 薄紫 | 注文書が存在するが、管理表に該当明細が見当たらない |
| **【警告】現品・請求 超過** | 赤 | 現品確認日・請求日の両方が納期を超過している |
| **【現品超過】現品未確認** | 橙 | 注文書納期を過ぎているが、管理表の現品確認日（A列）が未記入 |
| **【請求超過】伝票未確認** | 黄 | 現品は入荷済だが、請求日（AI列）が未記入・未処理 |
| **正常 / 確認済** | 白 | 納期前、または現品・請求ともに確認が完了している |

### タブ②: 【未発注・注文書なし】管理表のみ記載 一覧

| 状態判定 | 背景色 | 状態・内容 |
| :--- | :--- | :--- |
| **未発注 (注文書なし)** | 薄橙/琥珀 | 管理表に登録されているが、対応する注文書ファイルが存在しない（※AB列購入数0は除外） |

## 💻 動作環境・必要ライブラリ

* **OS**: Windows 10 / 11
* **Python**: 3.9 以上
* **必要ライブラリ**:
  * `openpyxl >= 3.1.2`
  * `pandas >= 2.1.0`
  * `scipy >= 1.9.0` （任意：線形和割り当て最適化用。未インストール環境でも内蔵フォールバックにより正常動作します）
  * `tkinter`（Python標準付属）

## 📖 操作手順

1. **アプリの起動（自動最大化）**:
   ```bash
   python app.py
   ```
2. **パスの確認・保存**:
   * **① 注文品管理表ファイル** と **② 注文書フォルダパス** を指定します。
   * **「パス設定を保存」** ボタンを押すとアプリフォルダ直下の `config.json` に設定が保存されます。
3. **照合の実行**:
   * **「照合・遅延チェック実行」** ボタン（または `F5` キー）を押します。
4. **結果の確認**:
   * **タブ①「納期超過・照合結果 一覧」**: 日常の納期遅れ確認や管理表未登録チェックを行います。
   * **タブ②「【未発注・注文書なし】管理表のみ記載 一覧」**: AB列の購入数0（在庫充当品等）を除外した、本当に手配が必要な未発注案件を集中チェックできます。
   * どちらの一覧も行を **ダブルクリック** することで詳細情報ウィンドウが開きます。
5. **出力**:
   * **「CSV/Excel出力」**（`Ctrl+S`）で2シート構成のExcelファイルを保存できます。
