# StockMatch_Miya-v1.0.0

**StockMatch_Miya-v1.0.0** は、指定した **「注文書フォルダ（サブフォルダ含む全階層）」内の全注文書Excelファイル** と **「注文品管理表（1ファイル）」** を自動照合し、判定基準日（今日など）時点で **「現品確認日（実際の物を確認した日：A列）」** および **「請求日（伝票を確認した日：AI列）」** がそれぞれ納期を超過している明細を可視化・抽出するデスクトップ業務アプリケーションです。

---

## 📌 主な機能と特徴

### 1. 「どこが不一致か」が一目でわかる不一致診断・項目別比較機能
- 一覧テーブルの2列目に **「不一致理由・照合診断」** 列を搭載しており、なぜ不一致と判定されたのかが具体的に表示されます：
  - **【管理No未登録 / 管理No不一致】**: 注文書ファイル名先頭8桁の管理Noが管理表に1件も存在しない場合（または管理表の別管理Noに同一品が存在する場合、そのシート名・行番号と管理Noを明示）。
  - **【項目不一致】**: 管理Noは管理表に存在するものの明細が一致しなかった場合、同一管理No内で最も近い管理表の候補行を特定し、**「図番」「品番」「品名」「仕様」のどれが一致していて、どれが不一致なのか**（例：`一致:図番,品名 / 不一致:品番[注文:7-2≠管理:7-1]`）を表示。
  - **【重複・行数不足】**: 管理表に同一品はあるが、注文書に複数行あり管理表側の行がすでに別明細で消費済みの場合。
- **ダブルクリックで詳細比較ウィンドウを起動**:
  - 一覧の行を **ダブルクリック**（または「🔍 選択行の不一致・照合詳細を表示」ボタンをクリック）すると、**「注文書の記載内容」と「注文品管理表の候補行の記載内容」を9項目（管理No・図面番号・品番・品名・仕様・メーカー・数量・単価・金額）並べて比較する診断ウィンドウ** が開きます。

### 2. 管理No（ファイル名先頭8桁）の完全一致照合ルール
- **注文書ファイル名の頭から8桁を「管理No（注文番号）」として厳密に取得** します（例: `22609030購依（株）キーエンス注文.xlsx` ⇒ 管理No: `22609030`）。
- 注文品管理表の中に、この **管理No（8桁）と一致するデータが存在しない場合は、無条件で「【不一致】管理表未記載」** と判定されます。

### 3. 注文書フォルダ（サブフォルダ含む全階層）の一括検査
- 注文書が入った親フォルダを指定すると、**直下だけでなく配下のすべてのサブフォルダ（年・月・取引先別フォルダ等）内も再帰的に自動探索** して注文書Excelをまとめてスキャン・検査します。
- フォルダ内に混在する **PDF、画像、CSV、テキスト、一時ファイル（`~$`）、管理表自身、および注文書フォーマットではない無関係なExcel** は下層フォルダ内であってもすべて自動的に無視・スキップされます。

### 4. 起動時フルスクリーン最大化表示 & 設定保存先の厳重ブロック (`C:\StockMatch\config.json` 専用固定)
- アプリ起動時にデスクトップ画面いっぱいに **自動最大化（Maximized / Zoomed）** して起動します。
- 保存先は `C:\StockMatch\config.json` に厳格固定されており、**これ以外のいかなるディレクトリへの保存や既存ファイルの上書きもプログラム側で完全にブロック・拒否** します。

### 5. 購入依頼（購依）と外注依頼（外依）の自動切り分け
- ファイル名に **「購依」** が含まれるファイルは【購入依頼】として、管理表の「購入品リスト」系シートを優先照合します。
- ファイル名に **「外依」** が含まれるファイルは【外注依頼】として、管理表の「外注加工リスト」系シートを優先照合します。
- **「発注先」**（注文書の宛先・仕入先、例：`（株）キーエンス`）と **「メーカー」**（製造元、例：`ｷｰｴﾝｽ`）を別々の独立した列として正確に抽出・表示します。

### 6. 「現品確認日（物）」と「請求日（伝票）」の個別超過判定
- **現品確認日（A列）**: 管理表のA列に日付や確認済み文字が記入されていれば正常、未記入で納期超過していれば「未確認 (超過X日)」と表示。
- **請求日（AI列）**: 管理表のAI列に日付や確認済み文字が記入されていれば正常、未記入で納期超過していれば「未確認 (超過X日)」と表示。

## 💻 動作環境・必要ライブラリ

- **OS**: Windows 10 / 11
- **Python**: 3.9 以上
- **必要ライブラリ**:
  - `openpyxl >= 3.1.2`
  - `pandas >= 2.1.0`
  - `tkinter`（Python標準付属）

---

## 📖 使い方

1. **アプリを起動**:
   ```bash
   python app.py
   ```
2. **パスの設定と照合実行**:
   - **① 注文品管理表ファイル** と **② 注文書フォルダパス** を選択し、**「照合・遅延チェック実行」** ボタンを押します。
3. **不一致箇所の確認**:
   - テーブル2列目の **「不一致理由・照合診断」** 列を確認します。
   - さらに詳しく見たい行を **ダブルクリック** すると、注文書と管理表の項目別比較ウィンドウが開き、どの項目がどう違っているかを確認できます。
