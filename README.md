# StockMatch_Miya-v1.0.0

**StockMatch_Miya-v1.0.0** は、指定した **「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイル** と **「注文品管理表（1ファイル）」** を自動照合し、判定基準日（今日など）時点で **「現品確認日（実際の物を確認した日：A列）」** および **「請求日（伝票を確認した日：AI列）」** がそれぞれ納期を超過している明細を可視化・抽出するデスクトップ業務アプリケーションです。

---

## 📌 主な機能と特徴

### 1. アプリ全ウィンドウへの `icon.ico` 適用（タスクバー対応）
* アプリと同じフォルダに配置された **`icon.ico`** を自動的に読み込み、メイン画面・不一致詳細比較ウィンドウ・ヘルプ画面・列フィルター画面・各種ダイアログのすべてにアイコンを設定します。
* Windowsのタスクバー上でもPython標準アイコンではなく、`icon.ico` が独立したアプリアイコンとして表示されます。

### 2. 照合管理No頭文字フィルター機能（カンマ区切りでの複数指定に対応）
* **開始数字（頭文字）の柔軟な指定・保存**:
  * 画面上の「照合管理No頭文字」欄で、照合対象とする管理No（8桁）の開始数字を指定できます（デフォルト: `2`）。
  * **単独指定の例**: `2` と入力 ⇒ `2` から始まる管理No（例: `22609030`, `22609051` など）のみを照合対象とし、`1` から始まる管理Noなどは自動的に除外します。
  * **複数指定の例**: `2, 3` や `126, 226` のように **カンマ区切り（または読点「、」区切り）で複数入力** ⇒ 指定したすべての頭文字に該当する注文書・明細をまとめて一括照合します。
  * **全件照合の例**: 入力欄を **空欄** にする ⇒ 頭文字による制限を行わず、すべての管理Noを照合します。

### 3. 見やすいタブ形式の「ヘルプ＆操作ガイド」（F1キー）
* ヘッダー右上の **「？ ヘルプ / 操作ガイド (F1)」** ボタンまたはメニューの「ヘルプ(H)」から、見出しや重要ポイントが色分け・整理された3タブ構成のガイドウィンドウをいつでも確認できます。
  * **タブ① 基本的な使い方・設定**: ファイル選択・管理No頭文字の複数指定方法・設定保存の手順
  * **タブ② 照合ルール・不一致診断の仕組み**: 単価・金額除外ルールや不一致理由の読み解き方
  * **タブ③ 便利機能・ショートカットキー**: Excel風列フィルター、ダブルクリック詳細比較、ショートカット一覧

### 4. アプリ配置フォルダへの設定保存（ポータブル運用対応）
* **アプリと同じフォルダ内の `config.json` に設定を保存**:
  * 「パス・設定を保存」ボタンを押すと、指定した「注文品管理表ファイルパス」「注文書フォルダパス」「照合管理No頭文字」がアプリ自身のフォルダ直下にある `config.json` に保存されます。
  * 次回起動時に前回の設定が自動復元されます（起動時の勝手な自動実行は行われず、ボタンを押したタイミングで照合を開始します）。

### 5. 注文書と見積依頼書の自動分別（シート2行目チェック）
* **見積依頼書の自動スキップ**:
  * 注文書フォルダ内のExcelシートの **2行目** を走査し、「見積」や「見積依頼」などの記載があるシートは自動的にスキップします。
  * **2行目に「注文」「発注」等の記載がある注文書シートのみを照合対象として抽出** するため、同じフォルダ内やブック内に見積依頼書が混在していても誤って取り込まれません。

### 6. 単価・金額の照合除外＆全体最適マッチング
* **単価・金額を照合対象から完全に除外**:
  * 管理表での単価未入力・金額0円、または税抜/税込の違いによる誤った不一致判定を防止しました。
  * 照合は **「①管理No」「②図面番号」「③品番」「④品名（管理表O列）」「⑤仕様・規格」「⑥発注先・メーカー」「⑦数量」** の7項目で行われます。
* **全体最適1対1マッチング**:
  * 同一管理No内の全明細と管理表候補行の間で、全体として最も整合性が高くなる最適な1対1ペアを自動決定します。別業者の注文書が他社の管理表行を誤って先取り消費してしまう問題を完全に防ぎます。

### 7. 「どこが不一致か」が一目でわかる不一致診断・項目別比較機能
* 一覧テーブルの2列目 **「不一致理由・照合診断」** 列に具体的な理由を表示します。
* さらに一覧の行を **ダブルクリック**（または「🔍 選択行の不一致・照合詳細を表示」ボタンをクリック）すると、注文書と管理表の記載内容を左右に並べて比較するウィンドウが開きます。

## 💻 動作環境・必要ライブラリ
* **OS**: Windows 10 / 11
* **Python**: 3.9 以上
* **必要ライブラリ**:
  * `openpyxl >= 3.1.2`
  * `pandas >= 2.1.0`
  * `scipy >= 1.9.0` （任意：線形和割り当て最適化用。未インストール環境でも内蔵フォールバックにより正常動作します）
  * `tkinter`（Python標準付属）

## 📖 操作手順
1. **アプリの起動（自動最大化）**:
   ```bash
   python app.py
   ```
   ※同じフォルダに `icon.ico` を置いておくと、すべてのウィンドウとタスクバーにアイコンが反映されます。
2. **パスと照合条件の確認・保存**:
   * **① 注文品管理表ファイル** と **② 注文書フォルダパス** を指定します。
   * **照合管理No頭文字** に `2`（複数指定する場合は `2, 3` などカンマ区切り、全件なら空欄）を入力します。
   * **「パス・設定を保存」** ボタンを押すと、アプリと同じフォルダ内の `config.json` に設定が保存されます。
3. **照合の実行**:
   * **「照合・遅延チェック実行」** ボタン（または `F5` キー）を押します。
4. **結果の確認・絞り込み・出力**:
   * 上部のKPIカードや表示フィルタ、各列ヘッダークリックによる **Excel風フィルター** で異常行や特定業者を絞り込めます。
   * 気になる行を **ダブルクリック** すると、注文書と管理表の項目別比較レポートを確認できます。
   * **「CSV/Excel出力」** ボタン（または `Ctrl+S`）で一覧をファイル出力できます。
