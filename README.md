StockMatch-v1.0.0

注文品管理表（1つのExcelファイル）の「現品確認日」「請求日」と、指定した注文書フォルダ内のすべての注文書Excelファイルの「納期」を照合し、今日（判定基準日）時点で現品確認や伝票（請求）が遅れている明細を即座に特定・一覧表示するデスクトップアプリケーションです。

主な機能

管理表ファイルパス指定 ＆ 注文書フォルダ一括スキャン

① 注文品管理表ファイル: 1つのExcelファイル（注文品管理表.xlsx 等）のパスを直接入力または「ファイルを参照...」から指定できます。

② 注文書フォルダパス: 注文書が入っているフォルダのパスを直接入力または「フォルダを参照...」から指定すると、フォルダ内のすべての注文書を自動的に確認します。

注文書以外のファイル自動除外: 注文書フォルダ内に注文書以外のファイル（管理表自身、Excelの一時ファイル ~$、PDF・画像・テキスト、または注文書フォーマットではない無関係なExcelファイル等）が含まれている場合は自動的に無視します。

現品確認日（物）・請求日（伝票）それぞれの超過判定

現品確認日の超過: 今日（判定基準日）が注文書の納期を過ぎているにもかかわらず、管理表の「現品確認日」が未入力のものを検出します。

請求日の超過: 今日（判定基準日）が注文書の納期を過ぎているにもかかわらず、管理表の「請求日」が未入力のもの（または現品確認済みなのに伝票が未着のもの）を検出します。

色分けハイライトとワンクリック絞り込み

赤色（【警告】現品・請求 超過）: 現品確認日・請求日の両方が超過している明細

オレンジ色（【現品超過】現品未確認）: 現品確認日が超過している明細

黄色（【請求超過】伝票未確認）: 現品は確認済みだが請求日（伝票）が超過している明細

ラジオボタンで「すべての超過」「現品確認日の超過のみ」「請求日の超過のみ」「現品・請求の両方超過」「全件表示」を即座に切り替えられます。

レポート出力（Excel / CSV）

判定結果一覧を .xlsx または .csv 形式で保存できます。

セットアップと起動方法

1. 依存パッケージのインストール

pip install -r requirements.txt


2. アプリケーションの起動

python app.py


使い方

アプリを起動します（同じフォルダに 注文品管理表.xlsx や注文書Excelがある場合は起動時に自動認識して初回チェックを実行します）。

① 注文品管理表ファイル に管理表のファイルパスを指定します（直接入力または「ファイルを参照...」ボタン）。

② 注文書フォルダパス に注文書が入っているフォルダのパスを指定します（直接入力または「フォルダを参照...」ボタン）。

③ 判定基準日 (今日) に今日の日付（YYYY-MM-DD）が入っていることを確認し、「照合・遅延チェック実行」 ボタンを押します。

一覧表にて、どの注文番号・発注先・品名・型番が何日遅れているか（現品確認日・請求日それぞれの状態）を確認できます。

必要に応じて 「CSV/Excel出力」 ボタンから結果をファイルに出力できます。
