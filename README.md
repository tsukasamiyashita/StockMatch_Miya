# StockMatch_Miya-v1.1.0

StockMatch_Miya-v1.1.0 は、指定した「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイルと「注文品管理表（1ファイル）」を双方向で自動照合し、判定基準日（今日など）時点で「現品確認日（実際の物を確認した日：A列）」および「請求日（伝票を確認した日：AI列）」がそれぞれ納期を超過している明細、ならびに「注文書未検出（管理表にあるのに注文書が見当たらない未発注明細）」を個別のタブで明確に分離して可視化・抽出するデスクトップ業務アプリケーションです。

---

## 主な機能と特徴

### 1. タブ分離による2系統の独立一覧表示
* タブ①『納期超過・照合結果 一覧』:
  * 注文書が存在する案件の納期超過（現品確認・請求日）および、管理表に未登録の案件（【不一致】管理表未記載）を一覧表示。
  * 【初期表示フィルタ】照合実行時、最も緊急性の高い「現品・請求の両方超過」がデフォルトで選択されて表示されます。必要に応じてラジオボタンで「すべての異常」「現品確認日の超過」「請求日(伝票)の超過」「全件表示」等にワンクリックで切り替え可能です。
* タブ②『【未発注・注文書なし】管理表のみ記載 一覧』:
  * 注文品管理表に明細が登録されているにもかかわらず、注文書フォルダ内に注文書Excelが存在しない未手配・未発注案件だけを独立して一覧表示。
  * 【AB列「購入数」0の自動除外】注文品管理表のAB列（28列目）「購入数」を正確に参照し、購入数が「0」（または「0.0」、全角の「０」等）となっている在庫充当品や発注不要・キャンセル等の項目は未発注一覧から自動的に除外されます。

### 2. 注文書の納期未記載時の自動期日算出（注文日基準の超過判定）
* 注文書明細の納期が空欄（未記載）の場合、注文書4行目に記載されている「注文日（発注日付）」を自動抽出します。
* 注文日から指定日数（デフォルト: 7日）を経過した時点で超過とみなして判定を行います。
* 画面上の「納期未記載時: 注文日(4行目)から [ 7 ] 日経過で超過」入力欄から日数を自由に設定できます。
* 「設定を保存」ボタンを押すことで、管理表パス・注文書フォルダパスとともに次回起動時にも自動的に復元・引き継がれます。

### 3. 一時ファイルなしでExcel新規ブックへ直接展開
* 「📊 Excelで直接開く」機能（ショートカットキー: Ctrl + S）:
  * ディスク上に一時ファイルを作成せず、Excelの新規ブック（未保存のBook）を直接起動して全データを即座に転送・展開します。
  * アプリと同じ配色（薄赤・薄橙・薄黄・薄紫・琥珀色）を完全再現。
  * シート1・シート2ともにヘッダー行にオートフィルターを設定し、スクロールしても見出し（1行目）が隠れないようウィンドウ枠固定（FreezePanes）が自動設定されます。

### 4. 高精度マッチング＆単価・金額の除外
* 単価未入力や金額0円、消費税表記の違いによる誤判定を防ぐため、単価・金額は照合計算から完全に除外しています。
* 照合は「①管理No(8桁)」「②図面番号」「③品番」「④品名」「⑤仕様・規格」「⑥発注先・メーカー」「⑦購入数(AB列)」で高精度に行われます。
* 同一管理No内の全明細に対して全体最適マッチングを行い、他業者の注文書による誤った先取り消費を防止します。

## 動作環境

* 対応OS: Windows 10 / Windows 11 (64bit)
* 必要ソフトウェア: Microsoft Excel（「Excelで直接開く」機能を利用する場合）
* 追加のインストール作業（Python環境構築等）は不要です。配布された `.exe` ファイル単体ですぐに動作します。

---

## インストール・実行方法

1. 配布された `StockMatch_Miya-v1.1.0.exe` を任意のフォルダ（デスクトップや専用フォルダなど）に配置します。
2. `StockMatch_Miya-v1.1.0.exe` をダブルクリックして起動します。

### 初回起動時のWindows Defender（SmartScreen）警告への対応手順

初めて本アプリを実行した際、Windowsのセキュリティ機能（Microsoft Defender SmartScreen）により以下の青い警告画面が表示される場合があります。

> 「WindowsによってPCが保護されました」
> 「Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起きる可能性があります。」

この警告が表示された場合は、以下の手順で実行してください。

1. 画面内に表示されている「詳細情報」という下線付きリンクをクリックします。
2. リンクをクリックすると隠れていた「実行」ボタンが右下に現れます。
3. 「実行」ボタンをクリックすると、アプリが正常に起動します。

※本アプリは安全な業務ツールですので、安心して「実行」を選択してください。2回目以降の起動時はこの警告画面は表示されなくなります。

## 基本的な使い方

1. アプリを起動します（画面は自動的に最大化されて開きます）。
2. ファイルとフォルダを指定します:
   * ① 注文品管理表ファイル: 「ファイルを参照...」から管理表Excel（例: 注文品管理表.xlsx）を選択します。
   * ② 注文書フォルダパス: 「フォルダを参照...」から注文書Excelが保存されているフォルダを選択します（※配下のサブフォルダ内も全階層自動で探索されます）。
   * 「設定を保存」ボタンを押しておくと、指定パスおよび納期未記載時の超過日数が次回起動時も自動で読み込まれます。
3. 判定基準日および納期未記載時の超過日数を設定します:
   * 判定基準日の初期値は「今日」の日付が設定されています。過去の特定日時点での遅延状況を確認したい場合は日付を変更できます。
   * 「納期未記載時: 注文日(4行目)から [ 7 ] 日経過で超過」にて、納期が空欄の場合の超過猶予日数（初期値: 7日）を設定できます。
4. 「照合・遅延チェック実行」ボタン（または F5 キー）をクリックします。
   * 自動的に管理表と注文書が照合され、結果が一覧表示されます。
5. 結果を確認します:
   * タブ①『納期超過・照合結果 一覧』: 初期状態では最も優先確認が必要な「現品・請求の両方超過」に絞り込まれて表示されます。表示フィルタのラジオボタンで他の条件（全件表示や管理表との不一致等）にいつでも切り替えられます。注文書納期が未記載で注文日から設定日数経過した項目は、超過日数および「未記載 (YYYY-MM-DD注文+X日)」が表示されます。
   * タブ②『【未発注・注文書なし】管理表のみ記載 一覧』: 注文書が未手配の案件一覧を確認できます（※購入数0の品目は自動除外されています）。
   * 一覧の行をダブルクリックすると、注文書と管理表の項目別詳細比較ウィンドウが開きます。
6. Excelで開く:
   * 「📊 Excelで直接開く」ボタン（または Ctrl + S キー）を押すと、Excelが起動して色分け・フィルター・見出し固定済みの新規シートとして直接確認・保存ができます。
