StockMatch-v1.0.0StockMatch-v1.0.0 は、指定した 「注文書フォルダ」内の全注文書Excelファイル と 「注文品管理表（1ファイル）」 を自動照合し、判定基準日（今日など）時点で 「現品確認日（実際の物を確認した日：A列）」 および 「請求日（伝票を確認した日：AI列）」 がそれぞれ納期を超過している明細を可視化・抽出するデスクトップ業務アプリケーションです。📌 主な機能と特徴1. パス設定の明示的保存 (C:\StockMatch\config.json)管理表ファイルパスと注文書フォルダパスを指定し、「パス設定を保存」 ボタン（またはメニューの「設定」→「現在のパス設定を保存」）をクリックすると、C:\StockMatch\config.json に設定が保存されます。アプリ起動時には前回のパスが自動で入力欄に復元されます。起動時に自動処理は走らず、準備ができてから 「照合・遅延チェック実行」 ボタンを押す仕様のため安心です。2. 注文書フォルダの一括検査 ＆ 無関係ファイルの自動無視注文書が入ったフォルダを指定するだけで、中にある注文書Excelをまとめてスキャン・検査します。フォルダ内に混在する PDF、画像、CSV、テキスト、一時ファイル（~$）、管理表自身、および注文書フォーマットではない無関係なExcel はすべて自動的に無視・スキップされます。3. 購入依頼（購依）と外注依頼（外依）の自動切り分けファイル名に 「購依」 が含まれるファイルは【購入依頼】として、管理表の「購入品リスト」系シートを照合します。ファイル名に 「外依」 が含まれるファイルは【外注依頼】として、管理表の「外注加工リスト」系シートを照合します。「発注先」（注文書の宛先・仕入先、例：（株）キーエンス）と 「メーカー」（製造元、例：ｷｰｴﾝｽ）を別々の独立した列として正確に抽出・表示します。4. 図面番号・品番による単独特定 ＆ 表記ゆれ吸収注文書に 図面番号 または 品番 が記入されている場合、スペース・中点（・）・ハイフン・カッコ等の記号を完全除去した英数字文字列のみを参照し、他の項目にブレることなく一発で管理表の行を特定します。図面番号・品番が空欄の明細に限り、品名・仕様・数量などのあいまい照合で補完します。管理表のどの行にも見当たらない明細は 「【管理表未記載】」 として表示されます。5. 「現品確認日（物）」と「請求日（伝票）」の個別超過判定現品確認日（A列）:管理表のA列に日付や確認済み文字（済 や ○ 等）が記入されている場合 ➡ 超過なし（正常/確認済）未記入で、判定基準日（今日）が注文書の納期を超過している場合 ➡ 「現品超過（物未確認）」請求日（AI列）:管理表のAI列に日付や確認済み文字が記入されている場合 ➡ 超過なし（正常/確認済）未記入で、判定基準日（今日）が注文書の納期を超過している場合 ➡ 「請求超過（伝票未確認）」現品・請求の両方が遅れているものは 「【重要】現品・請求 共に超過」 として赤色で強調表示されます。6. Excel風オートフィルター・ソート機能各列のヘッダーをクリックすると、Excelと同じようなドロップダウンウィンドウが表示されます。昇順・降順ソート検索ボックスによる絞り込み(すべて選択) チェック連動各項目の個別チェックボックス選択列フィルター適用中の列にはヘッダーに [▼] が表示され、「列フィルター解除 (Excel風)」ボタンで全列を一括解除できます。7. 上部メニューバーとヘルプ機能「ヘルプ(H)」 メニューまたは画面右上の 「？ ヘルプ / ガイド」 ボタン（ショートカット: F1）から、操作ガイドや判定ロジックの詳細説明をいつでも確認できます。💻 動作環境・必要ライブラリOS: Windows 10 / 11Python: 3.9 以上必要ライブラリ:openpyxl >= 3.1.2pandas >= 2.1.0tkinter（Python標準付属）🚀 インストール手順本リポジトリのファイル群を任意のフォルダに配置します。コマンドプロンプトまたは PowerShell を開き、配置したフォルダへ移動します。必要パッケージをインストールします：pip install -r requirements.txt
📖 使い方アプリを起動:python app.py
パスの設定:① 注文品管理表ファイル: 「ファイルを参照...」から管理表Excel（例: 注文品管理表.xlsx）を選択。② 注文書フォルダパス: 「フォルダを参照...」から注文書が入っているフォルダを選択。パス設定を保存: ボタンを押して C:\StockMatch\config.json へ保存します（次回以降は自動で入力欄に読み込まれます）。照合の実行:判定基準日（今日）を確認し、「照合・遅延チェック実行」 ボタン（または F5 キー）を押します。進捗バーが進み、完了すると超過件数と一覧が表示されます。結果の確認と絞り込み:上部の「表示フィルタ」（現品超過のみ、請求超過のみ、両方超過など）やキーワード検索で対象を抽出できます。表の列ヘッダークリックでExcel風フィルターも利用可能です。結果の出力:「CSV/Excel出力」 ボタン（または Ctrl+S）を押すと、超過状況を含む一覧レポートを .xlsx または .csv 形式で保存できます。⌨ ショートカットキー一覧キー動作F1使い方・操作ガイド（ヘルプ）を表示F5照合・遅延チェックを実行Ctrl + O注文品管理表ファイルを選択Ctrl + D注文書フォルダを選択Ctrl + S検査結果をExcel / CSVに出力Alt + F4アプリケーションを終了📁 ファイル構成StockMatch/
