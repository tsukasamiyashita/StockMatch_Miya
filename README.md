# StockMatch_Miya-v1.1.0

StockMatch_Miya-v1.1.0 は、指定した「注文書フォルダ（サブフォルダ含む全階層）」内の注文書Excelファイルと「注文品管理表（1ファイル）」を双方向で自動照合し、判定基準日（今日など）時点で「現品確認日（実際の物を確認した日：A列）」および「請求日（伝票を確認した日：AI列）」がそれぞれ納期を超過している明細、ならびに「注文書未検出（管理表にあるのに注文書が見当たらない未発注明細）」を個別のタブで明確に分離して可視化・抽出するデスクトップ業務アプリケーションです。

---

## 主な機能と特徴

### 1. 直感的なコントロールパネル配置 ＆ 押しやすいボタン設計
* 入力と実行がひと目で分かるレイアウト:
  * 上部パネルは「①管理表ファイル選択」「②注文書フォルダ選択」「③判定基準日・超過設定」の入力エリアと、「④進捗状況 ＆ 照合実行」の実行エリアに綺麗に分離・整理されました。
  * 「💾 設定を保存」ボタンは「③ 判定基準日 (今日)」行の右側に配置され、パスや基準日・超過日数の入力後にそのまま自然な流れで保存できます。
  * メイン操作である「▶ 照合・遅延チェック実行 (F5)」ボタンは、進捗状況行の右端に大きく力強いロイヤルブルーの目立つボタンとして配置され、迷わず直感的に操作できます。
  * 「📊 Excelで直接開く」ボタンは、照合結果を確認する「現在の表示フィルタ」行（一覧の上部右端）に配置され、絞り込み状況を確認しながらスムーズにExcel展開へ進むことができます。

### 2. 件数サマリー一体型のワンクリック表示フィルタ ＆ 2系統タブ分離表示
* 件数表示カードと表示フィルタの一体化:
  * 画面中段の8つの件数サマリーカード（注文書明細 総数 / すべての異常 / 現品・請求の両方超過 / 現品確認日の超過 / 請求日(伝票)超過 / 管理表との不一致 / 正常・納期前・確認済 / 注文書未検出）それぞれにフィルター切替ボタンを搭載しています。
  * 各カードのボタン（またはカード全体）をクリックするだけで、その件数に対応する明細一覧へ即座に絞り込まれます。
  * 現在選択されているフィルターのカードは太枠カラーラインと「✔ フィルター表示中」ボタンで強調表示され、一覧上部の「現在の表示フィルタ」バッジにもリアルタイムで表示件数が反映されるため、どの条件の何件を見ているかがひと目で分かります。
* タブ①『納期超過・照合結果 一覧』:
  * 注文書が存在する案件の納期超過（現品確認・請求日）および、管理表に未登録の案件（【不一致】管理表未記載）を一覧表示。
  * 【初期表示フィルタ】照合実行時、最も緊急性の高い「【警告】現品・請求の両方超過」カードがデフォルトで選択されて表示されます。
* タブ②『【未発注・注文書なし】管理表のみ記載 一覧』:
  * 右端の「【別タブ】注文書未検出」カードのボタンを押す（またはタブ②を選択する）と、注文品管理表に明細が登録されているにもかかわらず注文書フォルダ内に注文書Excelが存在しない未手配・未発注案件だけを独立して一覧表示します。
  * 【AB列「購入数」0の自動除外】注文品管理表のAB列（28列目）「購入数」を正確に参照し、購入数が「0」（または「0.0」、全角の「０」等）となっている在庫充当品や発注不要・キャンセル等の項目は未発注一覧から自動的に除外されます。

### 3. 納期表記の柔軟な自動変換（上旬・中旬・下旬・月末等）および納期未記載時の自動期日算出
* 期間表記の自動期日変換:
  * 「11/上」「11/上旬」「11月上旬」「11月上」「11/初」「11月初旬」「11月頭」などが含まれる場合、その月の10日（例: 11月10日）までとして判定します。
  * 「11/中」「11/中旬」「11月中旬」「11月中」「11/中頃」「11月半ば」などが含まれる場合、その月の20日（例: 11月20日）までとして判定します。
  * 「11/下」「11/下旬」「11月下旬」「11月下」「11/末」「11月末」「11月末日」「11月いっぱい」「11月内」などが含まれる場合、その月の最終日（例: 11月30日、12月31日、2月28日/29日）までとして判定します。
  * 「11/上～中」「11/中～下」「11/10～15」などの期間幅がある表記は、後ろの期日を期限として自動判定します。また、「11/前半」（15日まで）、「11/後半」（月末まで）や和暦（令和・R表記）にも対応しています。
* 納期未記載（空白）時の注文日基準判定:
  * 注文書明細の納期が空欄（未記載）の場合、注文書4行目に記載されている「注文日（発注日付）」を自動抽出します。
  * 注文日から指定日数（デフォルト: 7日）を経過した時点で超過とみなして判定を行います。
  * 画面上の「納期未記載時: 注文日(4行目)から [ 7 ] 日経過で超過」入力欄から日数を自由に設定でき、③の行にある「💾 設定を保存」ボタンを押すことで管理表パス・注文書フォルダパスとともに次回起動時にも自動的に復元・引き継がれます。

### 4. 注文品管理表・注文書のピンポイント直接参照＆注文書の厳重な誤保存・誤編集ブロック機構
* 該当シート・該当行へのExcelダイレクトジャンプ:
  * 一覧で明細を選択し、ツールバーの「📄 注文書を参照 (読取専用)」「📋 管理表を参照」ボタンを押すか、行を「右クリック」してメニューを選択すると、実際の注文書Excelまたは注文品管理表Excelを開き、該当するシートの該当行を自動選択（スクロール移動・ハイライト）した状態で表示します。
* 注文書の多重誤保存・誤編集ブロック（5重の安全保護）:
  * 注文書をアプリからExcelで開く際は、予期せず間違って編集・上書き保存してしまう事故を完全に防ぐため、以下の5重の保護が自動的に適用されます。
    1. 強制読み取り専用オープン: 常にExcelの「読み取り専用（ReadOnly）」モードで開きます。
    2. 既存ブックの読み取り専用強制切り替え: すでにExcel上でその注文書が通常モードで開かれていた場合でも、自動的に読み取り専用モードへ切り替えます。
    3. メモリ上の全シート＆ブック構造ロック: 開いた注文書シートに対してメモリ上で編集保護ロック（セル選択・スクロール・コピーは可能、文字入力やセル書き換え・行列削除は禁止）を適用します。
    4. 閉じる際の「変更を保存しますか？」ポップアップ抑止: 注文書内の日付関数（TODAY関数等）の再計算によってExcel終了時に「変更を保存しますか？」と聞かれる現象自体を抑止し、そのまま安全に閉じられるように制御します。
    5. 通常モード起動の完全遮断とファイル書き込み禁止ガード: 万が一Excel連携機能が使用できない環境でも通常モード（編集可能）で開くことを厳重にブロックし、アプリ自身も注文書や管理表ファイルへの書き込みを一切行わない安全設計となっています。
* 詳細ウィンドウ内の3タブ構成（アプリ内シートプレビュー）:
  * 一覧の行をダブルクリック（または「🔍 照合詳細・プレビュー」ボタンをクリック）すると開く詳細ウィンドウに、以下の3つのタブを搭載しています。
    1. 『① 🔍 項目比較・診断レポート』: 注文書と管理表の項目ごとの比較と不一致理由の診断を表示。
    2. 『② 📄 注文書シート参照 (プレビュー)』: Excelを開かなくても、注文書シートの記載内容（4行目の注文日や明細行など）をアプリ内の表で安全に確認でき、該当明細行が黄色でハイライト表示されます。
    3. 『③ 📋 注文品管理表参照 (同一管理No・周辺行)』: 管理表内の同じ管理Noの行や前後行をアプリ内で即座に一覧確認でき、ダブルクリックでExcelの該当行へ直接ジャンプできます。
* 上部パネルからのクイック起動:
  * 画面上部のファイル指定欄にある「📋 管理表を開く」「📂 フォルダを開く」ボタンから、いつでも注文品管理表や注文書保存フォルダを直接開くことができます。

### 5. 一時ファイルなしでExcel新規ブックへ直接展開＆最適な印刷設定
* 「📊 Excelで直接開く」機能（ショートカットキー: Ctrl + S）:
  * ディスク上に一時ファイルを作成せず、Excelの新規ブック（未保存のBook）を直接起動して全データを即座に転送・展開します。一覧上部の現在の表示フィルタ行（右端）にある緑色ボタンからいつでもワンクリックで呼び出せます。
  * アプリと同じ配色（薄赤・薄橙・薄黄・薄紫・琥珀色）を完全再現。
  * シート1・シート2ともにヘッダー行にオートフィルターを設定し、スクロールしても見出し（1行目）が隠れないようウィンドウ枠固定（FreezePanes）が自動設定されます。
* 業務帳票としての最適な印刷設定（自動適用）:
  * 用紙設定: 日本標準の「A4サイズ・横向き」に自動設定されます。
  * ページ自動調整: 表の横幅を用紙1ページ幅に自動で収める設定（FitToPagesWide=1）が適用され、右端の列が別ページにはみ出すのを防止します（縦方向はデータ件数に応じて自然に次ページに流れます）。
  * タイトル行の自動繰り返し: 2ページ目以降にも見出し行（1行目）が自動的に繰り返し印刷されます。
  * ヘッダー・フッター: ヘッダー左に帳票名、ヘッダー右に作成日、フッター中央にページ番号（例: 1 / 3 ページ）が自動設定されます。
  * グリッド線（枠線）の印字および余白の最適化が行われており、Excel上で「印刷」または「印刷プレビュー」を押すだけですぐに綺麗な帳票として印刷できます。

### 6. 高精度マッチング＆単価・金額の除外
* 単価未入力や金額0円、消費税表記の違いによる誤判定を防ぐため、単価・金額は照合計算から完全に除外しています。
* 照合は「①管理No(8桁)」「②図面番号」「③品番」「④品名」「⑤仕様・規格」「⑥発注先・メーカー」「⑦購入数(AB列)」で高精度に行われます。
* 同一管理No内の全明細に対して全体最適マッチングを行い、他業者の注文書による誤った先取り消費を防止します。

## 動作環境

* 対応OS: Windows 10 / Windows 11 (64bit)
* 必要ソフトウェア: Microsoft Excel（「Excelで直接開く」機能やシート行ジャンプ機能を利用する場合）
* 追加のインストール作業（Python環境構築等）は不要です。配布された `.exe` ファイル単体ですぐに動作します。

## インストール・実行方法

1. 配布された `StockMatch_Miya-v1.1.0.exe` を任意のフォルダ（デスクトップや専用フォルダなど）に配置します。
2. `StockMatch_Miya-v1.1.0.exe` をダブルクリックして起動します。

### 初回起動時のWindows Defender（SmartScreen）警告への対応手順

初めて本アプリを実行した際、Windowsのセキュリティ機能（Microsoft Defender SmartScreen）により以下の青い警告画面が表示される場合があります。

> 「WindowsによってPCが保護されました」
> 「Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起きる可能性があります。」

この警告が表示された場合は、以下の手順で実行してください。

1. 画面内に表示されている「詳細情報」という下線付きリンクをクリックします。
2. リンクをクリックすると隠れていた「実行」ボタンが右下に現れます。
3. 「実行」ボタンをクリックすると、アプリが正常に起動します。

※本アプリは安全な業務ツールですので、安心して「実行」を選択してください。2回目以降の起動時はこの警告画面は表示されなくなります。

## 基本的な使い方

1. アプリを起動します（画面は自動的に最大化されて開きます）。
2. ファイルとフォルダを指定します:
   * ① 注文品管理表ファイル: 「ファイルを参照...」から管理表Excel（例: 注文品管理表.xlsx）を選択します。「📋 管理表を開く」ボタンでいつでも管理表をExcelで開けます。
   * ② 注文書フォルダパス: 「フォルダを参照...」から注文書Excelが保存されているフォルダを選択します（※配下のサブフォルダ内も全階層自動で探索されます）。「📂 フォルダを開く」ボタンで保存先フォルダをすぐに開けます。
3. 判定基準日および納期未記載時の超過日数を設定し、設定を保存します:
   * 判定基準日の初期値は「今日」の日付が設定されています。過去の特定日時点での遅延状況を確認したい場合は日付を変更できます。
   * 「納期未記載時: 注文日(4行目)から [ 7 ] 日経過で超過」にて、納期が空欄の場合の超過猶予日数（初期値: 7日）を設定できます。
   * ③の行の右側にある「💾 設定を保存」ボタンを押しておくと、指定パスおよび納期未記載時の超過日数が次回起動時も自動で読み込まれます。
4. 進捗状況行の右端にある目立つボタンで照合を実行します:
   * ひときわ目立つ青色の「▶ 照合・遅延チェック実行 (F5)」ボタン（またはキーボードの F5 キー）をクリックします。
   * 自動的に管理表と注文書が照合され、結果が一覧表示されます。
5. 件数カードのボタンを押して結果を確認・元データを参照します:
   * 画面中段にある各件数カードのボタン（「▼ この条件で表示」「▼ 全件を表示」「▷ 未発注タブを表示」など）を押すと、見たい条件の明細一覧にワンクリックで切り替わります（初期状態では最も優先確認が必要な「【警告】現品・請求の両方超過」が選択されています）。
   * 注文書・管理表の直接参照: 行を選択して「📄 注文書を参照 (読取専用)」「📋 管理表を参照」ボタンを押すか、行を右クリックすると、該当ファイルの該当シート・該当行へ直接ジャンプしてExcelで確認できます（注文書は誤保存防止のため、常に読み取り専用・セル編集ロック状態で開かれます）。
   * 詳細・アプリ内プレビュー: 一覧の行をダブルクリックすると、項目別比較レポートに加え、アプリ内で注文書シートや管理表の周辺行を直接確認できるプレビュー画面が開きます。
6. 照合結果一覧をExcelで開く:
   * 一覧上部の現在の表示フィルタ行（右端）にある「📊 Excelで直接開く」ボタン（または Ctrl + S キー）を押すと、Excelが起動して色分け・フィルター・見出し固定済み、かつA4横・1ページ幅収まりの印刷設定が施された新規シートとして直接確認・印刷・保存ができます。
